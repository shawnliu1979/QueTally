# 雀帐-设计
- 设计微信小程序
    - 要求：
        - 初始界面
            - 界面描述：
                - 是一个由2个按钮组成的画面
            - 按钮：
                - 组一个局
                - 加入别人
            - Action：
                - 组一个局：
                    - 跳转到微信好友界面，多选2-4个好友
                    - 然后后台以选中好友的id为组，开一个新局（状态为准备中）
                    - 如果选中的好友中有人已经加入了一个局（准备中，开始中都算，除了已终结可以忽略），则报错（好友xxx还在一个局里，要不换个人试试？）
                    - 选好成员后，跳转至开局设置界面
                - 加入别人：
                    - 跳转到微信好友界面，单选一个好友
                    - 当该好友id下有一个准备中的局的话，加入该局
                    - 如果没有，则报错（您选择的好友没有开局哦）
                    - 跳转至开局设置界面（查看模式）
        - 开局设置界面：
            - 界面描述：
                - 一个成员确认列表（可以是微信昵称或备注名，和微信好友列表的表示一致）
                - 一个初始点数输入框（默认550点）
                - 一个开始按钮（查看模式的话，按钮时灰的 不可用）
                - 一个取消按钮
            - Action
                - 初期：
                    - 只有开局的人可以设置初始点数，其他人是不可用状态
                - 定时刷新：
                    - 成员确认列表根据实时加入人数刷新
                - 开始：
                    - 只有开局的人可以点击开始，点击后跳转主界面
                    - 其他人是灰色的
                        - 如果当时开局的人未点击开始，显示开始（等待中），点击后变为开始（3秒倒数读秒）
                        - 如果当时已开局，则显示开始（10秒倒数读秒），
                        - 读秒结束后跳转主界面
                - 取消：
                    - 退回到初始界面
        - 主界面
            - 界面描述：
                - 主界面上有3-5个人物按钮（有局内人数决定），还有个结算按钮
                - 人物按钮的标签上显示人物名称（可以是微信昵称或备注名，和微信好友列表的表示一致）
                - 还有一个当前点数显示框（可以为负数）
                - 一个局内明细link
            - Action：
                - 人物按钮：
                    - 点击后，跳转给付小窗口，输入给付点数，点确认给对应的好友
                    - 确认后，退回主界面，划转点数被锁定，主界面点数被扣除（假），等待对方好友确认后，正式扣除（真）
                    - 如果2分钟后未确认，或对方点击拒绝，则退回原账户
                - 定时刷新：
                    - 当有好友点击我方人物按钮划转点数时，跳出小窗口
                    - 小窗口上显示
                        - 划转源用户名
                        - 划转点数
                        - 划转前后自己点数明细
                        - 确认按钮+拒绝按钮
                    - 确认
                        - 确认点数划转，给划转源一个确认消息，点数入帐，退回主界面刷新点数
                    - 拒绝
                        - 给划转源一个拒绝消息，点数不入帐，退回主界面
                    - 小窗口显示2分钟后无操作的话，给划转源一个超时消息，点数不入帐，退回主界面
                - 结算按钮：
                    - 跳转结算画面
                - 局内明细Link：
                    - 显示一个列表，汇总该局内和自己有关的点数划转记录（包括成功，确认中，失败三种状态）
                    - 记录内容包括
                        - 划转方向（谁 -> 谁）
                        - 划转点数
                        - 划转前点数小记
                        - 划转后点数小记
        - 结算画面
            - 界面描述
                - 一个初始点数表示框
                - 一个当前点数表示框，可以为负
                - 一个结余表示框，可以为负（）
                - 一个结算按钮
            - Action
                - 初期
                    - 初始点数表示框里的点数由本次开局设置界面决定
                    - 当前点数表示框由最后一次划转后的点数决定
                        - 如果还有未划转成功的记录的话，该表示框边上显示有未划转记录
                    - 结余表示框 = 当前点数 - 初始点数
                - 结算
                    - 跳转至该局内点数最高的人的转账画面（如果政策允许的话）
        - 其他
            - 任何一个状态如果异常退出的话，下一次进入小程序需要能回到退出前的状态
            - 开局时的总点数应该和结算时的总点数一致
            - 本小程序纯属娱乐，不与金钱挂钩，不应出现任何金融属性的图标和符号
